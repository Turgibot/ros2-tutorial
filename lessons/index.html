ROS 2 and the Kinova Gen3

A step-by-step course for people new to ROS 2. You build a complete simulated Kinova Gen3 arm setup, one small idea per lesson, and every command shown here was run before it was written down.

Before you start

You need a Linux computer with a desktop session (tested on Ubuntu 24.04 with X11), at least 4 CPU cores (8 recommended), 12 GB RAM (16 recommended), 30 GB of free disk space and an internet connection. An NVIDIA GPU is optional. Lesson A0 includes a script that checks all of this for you.

You do not need to know ROS 2, Docker or robotics. You should be comfortable typing commands in a terminal. Every command block has a Copy button.

How each lesson works

  1. Goal: what you will have at the end.
  2. Concepts: only the new ideas, with a picture.
  3. Do it: numbered steps, with the output you should see.
  4. Check: one command that tells you it worked.
  5. Exercise: a short task, with the answer at the bottom.
  6. Recap: what to remember.
