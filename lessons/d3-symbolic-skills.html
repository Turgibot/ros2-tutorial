D3 · Symbolic actions as motion skills

"unstack B C" in, arm motion out: the layer that connects a plan to the pick-and-place of D2.

1. Goal

In A3 you wrote a mock server for the action /execute: it received "unstack F W" and pretended to do it in four phases. Now it does it. The server of this lesson speaks the same action, so the client of A3 works with it unchanged, but behind it are the estimator of D1 (the state of the world) and the pick-and-place of D2 (the motion). At the end you will have:

  • three skills, unstack X Y, stack X Y and putdown X, each with conditions checked against the symbolic state before anything moves,
  • the server of A3's action, /execute, that turns a skill into a goal for /pick_place,
  • a plan runner in Python and in C++ that runs a list of skills, and stops at the first failure,
  • a plan that swaps two blocks of a tower, run end to end in the simulator, and read back from /towers.
Remember the grip

As in D2, the blocks here are static models and a carried block is moved with set_pose: the arm moves for real, the grip is simulated. Everything else on this page (the state, the conditions, the plan) does not depend on that.

What was and was not run

Run in the course container, Gazebo headless: every command of the page, with the server in Python and the plan runners in Python and in C++, one swap plan of four actions and one reversal of a tower. The server has no C++ version, cancelling an action is not supported, and the real arm was not tried.

2. Concepts

Three layers

Conditions and effects

A symbolic action is only meaningful in some states: you cannot unstack a block that is not on top, or stack on a block that already has one on it. Each skill states what must be true before, and what will be true after. The table below is the whole definition:

SkillNeeds (before)Result (after)
unstack X YX is the top block of a tower, directly on YX alone on a free place of the table
putdown XX is the top block of a tower of two or moreX alone on a free place of the table
stack X YX is alone on the table; Y is the top of a tower with fewer than three blocksX on top of Y

Every skill also needs held to be empty: no block in the air, that is, the arm is still. The conditions look at the symbolic state only, the sentence of D1 (for example A | DCB), not at numbers.

The limit of three blocks comes from the reach of the hand (D2). It is a physical fact written into the conditions, so that the plan is refused here and not half-done by the arm.

Why not pickup

The classical blocks world has four actions, with the hand holding a block between two of them: pickup X and putdown X, unstack X Y and stack X Y. That needs the state "the hand holds X", and a pick-and-place that can stop in the middle. Here a skill is a complete pick and place, as in the mock of A3 (approach, grasp, lift, place were one action): the hand is empty before and after. So unstack X Y includes putting X down on the table, and putdown X is the same movement when you do not need to name the block below. pickup X alone is refused with a message that says so.

Where to put a block down

On the table there are four places, the four in the lab: x = 0.50 and y = −0.18, −0.06, 0.06, 0.18. A place is free if no block is within 4 cm of it. The skill chooses the free place closest to where the block is (the shortest move), computed from the block poses.

The same action as in A3

The goal is name and args (unstack, [B, C]), the feedback is a phase and a progress (0 to 1), the result a success and a message. The server passes on the nine stages of /pick_place as the phases, with the progress k/9. A failed condition is a result with success: false and the reason in message.

  3. The skills server

    #!/usr/bin/env python3
"""Action server /execute: the symbolic actions of the blocks world, carried out by the arm.

It speaks the Execute action of lesson A3 (name + args), so the clients of A3 work with it. Three skills:

  unstack X Y   X is on top of Y: put X on the table
  stack X Y     X is alone on the table, Y is the top of a tower: put X on Y
  putdown X     X is on top of a tower: put X on the table

Each skill first checks its conditions against the symbolic state (/towers, lesson D1) and refuses if they do not
hold. Then it works out where the block must go and asks /pick_place (lesson D2) to move it."""
import time

import rclpy
from a3_interfaces.action import Execute
from d2_interfaces.action import PickPlace
from geometry_msgs.msg import PoseStamped
from rclpy.action import ActionClient, ActionServer
from rclpy.callback_groups import ReentrantCallbackGroup
from rclpy.executors import MultiThreadedExecutor
from rclpy.node import Node
from rclpy.qos import DurabilityPolicy, QoSProfile
from std_msgs.msg import String

BLOCKS = "ABCD"
SIZE = 0.05
ON_TABLE_Z = 0.325                       # centre of a block on the table
SLOT_X = 0.5
SLOTS_Y = [-0.18, -0.06, 0.06, 0.18]     # the four places on the table where a block can be put down
MAX_HEIGHT = 3                           # the hand cannot reach the fourth level (lesson D2)
STAGES = ["open", "above", "descend", "grasp", "lift", "transit", "lower", "release", "retreat"]


def parse(text):
    """'A | CB | D   held: B' -> (['A', 'CB', 'D'], ['B']): the towers bottom to top, and the blocks in the air."""
    towers_part, _, held_part = text.partition("held:")
    towers = [t.strip() for t in towers_part.split("|") if t.strip()]
    return towers, held_part.split()


class Skills(Node):
    def __init__(self):
        super().__init__("skills")
        group = ReentrantCallbackGroup()
        self.towers, self.held = [], []
        self.pos = {}
        latched = QoSProfile(depth=1, durability=DurabilityPolicy.TRANSIENT_LOCAL)
        self.create_subscription(String, "/towers", self.on_towers, latched, callback_group=group)
        for k in BLOCKS:
            self.create_subscription(PoseStamped, f"/model/block_{k}/pose",
                                     lambda m, k=k: self.pos.__setitem__(k, (m.pose.position.x, m.pose.position.y, m.pose.position.z)),
                                     10, callback_group=group)
        self.pick_place = ActionClient(self, PickPlace, "pick_place", callback_group=group)
        self.server = ActionServer(self, Execute, "execute", execute_callback=self.execute, callback_group=group)
        self.get_logger().info("skills are ready: unstack X Y, stack X Y, putdown X")

    def on_towers(self, msg):
        self.towers, self.held = parse(msg.data)

    # ---- the conditions and the target of each skill ----------------------------------------------------------
    def tower_of(self, block):
        return next((t for t in self.towers if block in t), None)

    def free_slot(self, near_y):
        """The place on the table, free of blocks, that is closest to y = near_y."""
        free = [y for y in SLOTS_Y
                if all(abs(self.pos[b][1] - y) > 0.04 or abs(self.pos[b][0] - SLOT_X) > 0.04 for b in BLOCKS)]
        if not free:
            raise ValueError("there is no free place on the table")
        return min(free, key=lambda y: abs(y - near_y))

    def plan(self, name, args):
        """Check the conditions and return (block, x, y, z) for the pick-and-place, or raise ValueError."""
        if self.held:
            raise ValueError(f"block {self.held[0]} is in the air: wait until the arm is still")
        if name == "unstack" and len(args) == 2:
            x, y = args
            tower = self.tower_of(x)
            if tower is None or y not in tower:
                raise ValueError(f"unstack {x} {y}: unknown block, or the blocks are not in a tower")
            if tower.find(x) != tower.find(y) + 1 or not tower.endswith(x):
                raise ValueError(f"unstack {x} {y}: {x} is not the top block directly on {y} (towers: {' | '.join(self.towers)})")
            return x, SLOT_X, self.free_slot(self.pos[x][1]), ON_TABLE_Z
        if name == "putdown" and len(args) == 1:
            x = args[0]
            tower = self.tower_of(x)
            if tower is None:
                raise ValueError(f"putdown {x}: unknown block")
            if tower == x:
                raise ValueError(f"putdown {x}: {x} is already on the table")
            if not tower.endswith(x):
                raise ValueError(f"putdown {x}: {x} is not at the top of its tower (towers: {' | '.join(self.towers)})")
            return x, SLOT_X, self.free_slot(self.pos[x][1]), ON_TABLE_Z
        if name == "stack" and len(args) == 2:
            x, y = args
            if x == y or x not in BLOCKS or y not in BLOCKS:
                raise ValueError(f"stack {x} {y}: two different blocks of {BLOCKS} are needed")
            if self.tower_of(x) != x:
                raise ValueError(f"stack {x} {y}: {x} must be alone on the table (towers: {' | '.join(self.towers)})")
            tower = self.tower_of(y)
            if not tower.endswith(y):
                raise ValueError(f"stack {x} {y}: {y} is not clear, there is a block on it (towers: {' | '.join(self.towers)})")
            if len(tower) >= MAX_HEIGHT:
                raise ValueError(f"stack {x} {y}: the tower would be higher than {MAX_HEIGHT} blocks")
            px, py, pz = self.pos[y]
            return x, px, py, pz + SIZE
        raise ValueError(f"'{name} {' '.join(args)}' is not a skill: use unstack X Y, stack X Y or putdown X")

    # ---- the action -------------------------------------------------------------------------------------------
    def execute(self, goal_handle):
        name, args = goal_handle.request.name, list(goal_handle.request.args)
        text = f"{name} {' '.join(args)}"
        self.get_logger().info(f"execute: {text}")

        def finish(ok, message):
            (goal_handle.succeed if ok else goal_handle.abort)()
            self.get_logger().info(message)
            return Execute.Result(success=ok, message=message)

        try:
            block, x, y, z = self.plan(name, args)
        except ValueError as error:
            return finish(False, str(error))
        if not self.pick_place.wait_for_server(timeout_sec=5.0):
            return finish(False, "no /pick_place server")

        def relay(msg):                      # feedback of PickPlace -> feedback of Execute
            stage = msg.feedback.stage
            progress = (STAGES.index(stage) + 1) / len(STAGES) if stage in STAGES else 0.0
            goal_handle.publish_feedback(Execute.Feedback(phase=stage, progress=progress))

        send = self.pick_place.send_goal_async(PickPlace.Goal(block=block, x=x, y=y, z=z), feedback_callback=relay)
        while not send.done():                   # the executor's other threads complete the future
            time.sleep(0.01)
        handle = send.result()
        if not handle.accepted:
            return finish(False, "/pick_place refused the goal")
        done = handle.get_result_async()
        while not done.done():
            time.sleep(0.05)
        result = done.result().result
        return finish(result.success, f"{text}: done" if result.success else f"{text}: {result.message}")


def main():
    rclpy.init()
    node = Skills()
    executor = MultiThreadedExecutor(num_threads=6)
    executor.add_node(node)
    executor.spin()


if __name__ == "__main__":
    main()
    • plan is the table of the Concepts as code: for each skill it checks the conditions on the towers (self.towers, from /towers) and returns the block and the target (x, y, z), or raises a ValueError whose text becomes the message of a failed result.
    • The target of stack X Y is Y's position plus one block height, from Y's pose. The target of the other two is free_slot, on the table.
    • execute then sends the goal to /pick_place, passes its feedback on, and waits for the result.
    • The /towers subscription uses the same transient-local setting as the publisher (D1): the server knows the state at once when it starts.

  5. A plan

    A plan is a list of skills. The runner sends them one after the other, stops at the first one that fails, and prints the state at the end. container T5:

    #!/usr/bin/env python3
"""Run a plan, a list of symbolic actions separated by ';', one after the other, and stop at the first failure.

  run_plan.py "stack C D; stack B C"
"""
import sys

import rclpy
from a3_interfaces.action import Execute
from rclpy.action import ActionClient
from rclpy.node import Node
from rclpy.qos import DurabilityPolicy, QoSProfile
from std_msgs.msg import String


def main():
    if len(sys.argv) != 2:
        sys.exit('usage: run_plan.py "unstack B C; stack B D"')
    steps = [s.split() for s in sys.argv[1].split(";") if s.strip()]
    rclpy.init()
    node = Node("run_plan")
    towers = {}
    node.create_subscription(String, "/towers", lambda m: towers.update(text=m.data), 
                             QoSProfile(depth=1, durability=DurabilityPolicy.TRANSIENT_LOCAL))
    client = ActionClient(node, Execute, "execute")
    if not client.wait_for_server(timeout_sec=10.0):
        sys.exit("no /execute server: is execute_server.py running?")
    ok = True
    for step in steps:
        goal = Execute.Goal(name=step[0], args=step[1:])
        print(f"> {' '.join(step)}")
        send = client.send_goal_async(goal, feedback_callback=lambda m: None)
        rclpy.spin_until_future_complete(node, send)
        done = send.result().get_result_async()
        rclpy.spin_until_future_complete(node, done)
        result = done.result().result
        print(f"  {'done' if result.success else 'FAILED: ' + result.message}")
        if not result.success:
            ok = False
            break
    for _ in range(20):                       # let the last /towers message arrive
        rclpy.spin_once(node, timeout_sec=0.1)
    print("towers: " + towers.get("text", "?"))
    node.destroy_node()
    rclpy.shutdown()
    sys.exit(0 if ok else 1)


if __name__ == "__main__":
    main()
    // Run a plan, a list of symbolic actions separated by ';', one after the other, and stop at the first failure.
//   run_plan "stack C D; stack B C"
#include <chrono>
#include <cstdio>
#include <memory>
#include <sstream>
#include <string>
#include <vector>
#include <a3_interfaces/action/execute.hpp>
#include <rclcpp/rclcpp.hpp>
#include <rclcpp_action/rclcpp_action.hpp>
#include <std_msgs/msg/string.hpp>

using Execute = a3_interfaces::action::Execute;
using namespace std::chrono_literals;

static std::vector<std::string> split(const std::string &text, char sep) {
  std::vector<std::string> out;
  std::stringstream stream(text);
  std::string item;
  while (std::getline(stream, item, sep)) out.push_back(item);
  return out;
}

int main(int argc, char **argv) {
  if (argc != 2) {
    std::fprintf(stderr, "usage: run_plan \"unstack B C; stack B D\"\n");
    return 2;
  }
  rclcpp::init(argc, argv);
  auto node = rclcpp::Node::make_shared("run_plan");
  std::string towers = "?";
  auto sub = node->create_subscription<std_msgs::msg::String>(
      "/towers", rclcpp::QoS(1).transient_local(),
      [&towers](const std_msgs::msg::String::SharedPtr msg) { towers = msg->data; });
  auto client = rclcpp_action::create_client<Execute>(node, "execute");
  if (!client->wait_for_action_server(10s)) {
    std::fprintf(stderr, "no /execute server: is execute_server.py running?\n");
    return 1;
  }
  bool ok = true;
  for (const auto &text : split(argv[1], ';')) {
    std::vector<std::string> words;
    std::stringstream stream(text);
    std::string word;
    while (stream >> word) words.push_back(word);
    if (words.empty()) continue;
    Execute::Goal goal;
    goal.name = words[0];
    goal.args.assign(words.begin() + 1, words.end());
    std::printf("> %s\n", [&] { std::string t = goal.name; for (const auto &a : goal.args) t += " " + a; return t; }().c_str());
    auto handle_future = client->async_send_goal(goal);
    if (rclcpp::spin_until_future_complete(node, handle_future) != rclcpp::FutureReturnCode::SUCCESS) return 1;
    auto result_future = client->async_get_result(handle_future.get());
    if (rclcpp::spin_until_future_complete(node, result_future) != rclcpp::FutureReturnCode::SUCCESS) return 1;
    const auto result = result_future.get().result;
    std::printf("  %s%s\n", result->success ? "done" : "FAILED: ", result->success ? "" : result->message.c_str());
    if (!result->success) { ok = false; break; }
  }
  rclcpp::spin_some(node);
  std::printf("towers: %s\n", towers.c_str());
  rclcpp::shutdown();
  return ok ? 0 : 1;
}

6. Recap

  • A skill is a symbolic action with conditions (checked against the symbolic state) and an effect. Checking first means a bad plan is refused with the reason, before the arm moves.
  • Three layers: a plan (symbols), /execute (conditions and targets), /pick_place (motion), with the estimator closing the loop through /towers.
  • The server uses the action of A3 unchanged; the feedback carries the stages of D2.
  • Skills here are whole pick-and-place moves, so there is no pickup; towers are at most three blocks high; a free place on the table is chosen by distance.
  • A plan runner (Python and C++) runs the skills in order and stops at the first failure.
  • Not covered: planning (finding the list of skills for a goal, Part E), cancelling, a real grip (D2), the C++ server.
