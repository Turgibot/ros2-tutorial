# A6: frames and TF2

Code for lesson A6 (`lessons/a6-frames-tf2.html`). One colcon package, `a6_frames`, with the same two programs in Python (`py/`) and C++ (`cpp/`):

- `orbit`: broadcasts a moving frame `marker` that circles around `base`.
- `where`: looks up where a frame is, as seen from another (parameters `source`, `target`).

Build and run: see the lesson.
