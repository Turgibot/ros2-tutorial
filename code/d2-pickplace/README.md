# D2: pick and place

Code for lesson D2 (`lessons/d2-pick-and-place.html`). Two colcon packages: `interfaces/` (`d2_interfaces`: the PickPlace action) and `pickplace/` (`d2_pickplace`: the server `pick_place_server.py` in Python with `gen3.py`, the kinematics of B3, and clients in Python and C++).

The grip is simulated (blocks are static models carried with `set_pose`): see the lesson.

Build and run: see the lesson.
