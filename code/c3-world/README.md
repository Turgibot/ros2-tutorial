# C3 and C4: the lab world

Code for lessons C3 and C4. One colcon package, `c3_world`: `models/block_A..D`, `worlds/lab.sdf` (table, four lettered blocks, two cameras), `launch/lab.launch.py` (the world alone) and `launch/lab_arm.launch.py` (the arm in the lab; `static_blocks:=true` for D2/D3), and the programs `check_settled` and `block_tf` (Python and C++), `save_image.py` and `pixel_to_table.py` (Python tools).

Build and run: see the lessons.
